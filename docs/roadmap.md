## 현재 위치

**마일스톤 2 진행 · 나 카피 봇.** 마일스톤 1(모의 운영 기반)을 2026-10-02에 마쳤다 (태그 `milestone-1`). 개발 PC에서 운영 구성으로 실제 토스 시세 DRY RUN을 계속 돌리며, MWP 운영 검증(2주 무개입·백업 복원)은 마일스톤 2 기간에 함께 진행한다. Lightsail이 준비되면 DB를 옮긴다.

- 1999~ 구간의 매수 후 보유 값은 전략별 첫 체결일(warmup 길이)에 따라 다르다.
- 2010년 이후 강세장에서는 어떤 추세 전략도 매수 후 보유의 수익률을 넘지 못하고, 대신 낙폭을 줄인다. 1999년 고점에서 시작하면 50/200만 매수 후 보유를 앞선다.
- MWP의 목적은 파이프라인 검증이므로 거래가 적고 판단 근거가 단순한 50/200을 기본값으로 둔다. 과최적화를 피하려고 파라미터 탐색은 하지 않았다.

목표: **나 카피 봇 / 실제 나 / 매달 그냥 사기** 세 줄 비교 (project.md 1절). 가장 불확실한 것(실제 계좌 기록을 얼마나 가져올 수 있나)부터 확인한다. MWP 2주 운영 검증은 그대로 진행하고, 이 트랙은 운영 중인 봇을 건드리지 않게 기능을 추가하는 방식으로 간다.

| 단계 | 이름 | 상태 | 완료 기준 |
| --- | --- | --- | --- |
| N0 | 나처럼 모으기 | 완료 | 정기 입금·추가 매수·고점 쉬기·하락장 몰아 사기, 넣은 돈 기준 수익률, 매달 그냥 사기 비교 (#65, #67) |
| N1 | 실제 계좌 조사 | 완료 (2026-10-02) | 공식 문서 + 실제 계좌 1회 조회 (tossApi.md 9절). 첫 주문부터 전체 기록, 소수점 6자리, 원화 금액 없음(달러로 계산), `orderAmount`는 모든 체결에 있어 금액 주문 구분에 못 씀, 기록 밖 입고로 보유 수량과 소수점 이하 차이가 날 수 있음. 조회 중 운영 Worker 토큰이 무효화됐다가 자동 재발급됨 → N4에서는 Worker 안에서 조회한다 (원칙 6) |
| N2 | 규칙 틀 넓히기와 "나" 묶음 | 대기 | **종목은 최대 10개** (2026-10-02 결정): 실제 계좌가 있으면 넣은 돈 기준 상위 종목과 비중을 자동으로 찾아 "VOO·QQQ가 투자금의 95%예요"처럼 보여주고, 10개보다 적게 고르도록 안내와 선택지를 준다 (보통 2~5개면 충분). 나머지 종목은 비교에서 "기타"로 뺀다. 수십 개 종목을 사고파는 사용자는 대상이 아니다. **실제 거래 이력은 1달이면 충분하다** (실제 계좌 없이 질문만으로도 만들 수 있다). 종목 가격 이력은 규칙 지표(1년 최고가·200일 평균)만큼 필요하며, 상장 1년 미만 종목은 있는 만큼의 기간으로 계산한다. **모의 체결을 금액 기준·소수점 6자리로** 바꿔 주가보다 적은 월 금액도 그대로 산다 (토스 금액 주문과 같은 방식, tossApi.md 9절). 규칙 틀: 입금(주기·금액·날짜), 종목 비율(VOO 50 · QQQ 50), 고점 기준(200일선 +%·안 쉼), 하락 기준(-10/-15/-20%)과 그때 쓰는 돈(모은 돈 전부·절반), 매도(안 함·목표 수익에서 일부). **제안: 봇 하나가 여러 종목을 다룬다** (한 계좌·공유 현금, 종목별 비율, 하락장 때 모아 둔 돈을 떨어진 종목에 쓰기). 실제 계좌가 하나라 세 줄 비교도 계좌 단위가 자연스럽다. 기존 한 종목 전략은 종목이 하나인 경우로 그대로 동작 |
| N3 | 질문으로 나 만들기 | 대기 | 5~7개 쉬운 질문 → 규칙 틀 값 → 쉬운 말 요약 → "나처럼 10년 했다면" 즉시 백테스트(매달 그냥 사기와 비교) → 시작. AI 없이 선택지로 |
| N4 | 실제 나 불러오기와 세 줄 비교 | 대기 | Worker가 하루 한 번 실제 매수 기록을 읽어 "실제 나" 곡선을 만들고, 세 줄을 넣은 시점 반영 연 수익률로 비교. **닮은 정도**(지난 1년 카피 봇이 산 달과 실제로 산 달이 겹치는 비율)와 **규칙을 지켰다면 얼마였나**(나 카피 봇 − 실제 나, 금액) 표시 |
| N5 | 비교 화면을 홈 첫 화면으로 | 대기 | N4 결과가 의미 있으면 홈을 "나 vs 실제 나 vs 매달 그냥"으로. 월간 정리는 앱 안에서 ("이번 달 나 카피 봇은 쉬었고, 실제 나는 샀어요") |
| N6 | AI 인터뷰어 | 대기 | Claude API로 자유 대화 → 규칙 틀 JSON(구조화 출력, 스키마 검증) → N3 요약·백테스트 화면으로. 실제 기록이 규칙과 어긋나면 규칙 조정을 제안. 키는 `.secrets/`, 호출은 API 서버에서만, 대화 원문은 저장하지 않음 |
| N7 | 도메인과 바깥 접속 | 대기 | **마일스톤 2 마지막에 꼭 한다** (2026-10-02, 사용자 결정). 도메인 구매(**사용자**) → `cloudflared` 컨테이너로 Tunnel → Access로 본인 이메일만 허용 (project.md 6절). Tailscale 앱 없이 폰에서 도메인으로 접속되고, Access 로그인 없이는 화면·API 모두 막히며, 공개 인바운드 포트 0개 유지 |
