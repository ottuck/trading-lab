## 현재 위치

**마일스톤 2 진행 · 나 카피 봇.** 마일스톤 1(모의 운영 기반)을 2026-10-02에 마쳤다 (태그 `milestone-1`). 개발 PC에서 운영 구성으로 실제 토스 시세 DRY RUN을 계속 돌리며, MWP 운영 검증(2주 무개입·백업 복원)은 마일스톤 2 기간에 함께 진행한다. Lightsail이 준비되면 DB를 옮긴다.

- 1999~ 구간의 매수 후 보유 값은 전략별 첫 체결일(warmup 길이)에 따라 다르다.
- 2010년 이후 강세장에서는 어떤 추세 전략도 매수 후 보유의 수익률을 넘지 못하고, 대신 낙폭을 줄인다. 1999년 고점에서 시작하면 50/200만 매수 후 보유를 앞선다.
- MWP의 목적은 파이프라인 검증이므로 거래가 적고 판단 근거가 단순한 50/200을 기본값으로 둔다. 과최적화를 피하려고 파라미터 탐색은 하지 않았다.

목표: **나 카피 봇 vs 매달 그냥 사기, 그리고 평행세계의 나** (project.md 1절). 증권사 연동 없이 질문만으로 쓸 수 있게 한다 ("실제 나"는 2026-10-02 계획에서 뺐다). MWP 2주 운영 검증은 그대로 진행하고, 이 트랙은 운영 중인 봇을 건드리지 않게 기능을 추가하는 방식으로 간다.

| 단계 | 이름 | 상태 | 완료 기준 |
| --- | --- | --- | --- |
| N0 | 나처럼 모으기 | 완료 | 정기 입금·추가 매수·고점 쉬기·하락장 몰아 사기, 넣은 돈 기준 수익률, 매달 그냥 사기 비교 (#65, #67) |
| N1 | 실제 계좌 조사 | 완료 (2026-10-02) | 공식 문서 + 실제 계좌 1회 조회 (tossApi.md 9절). 첫 주문부터 전체 기록, 소수점 6자리, 원화 금액 없음(달러로 계산), `orderAmount`는 모든 체결에 있어 금액 주문 구분에 못 씀, 기록 밖 입고로 보유 수량과 소수점 이하 차이가 날 수 있음. 조회 중 운영 Worker 토큰이 무효화됐다가 자동 재발급됨. "실제 나"를 계획에서 빼서 결과는 실거래 단계(마일스톤 3)용으로 남긴다 |
| N2 | 규칙 틀 넓히기와 "나" 묶음 | 완료 | **완료 (2026-10-02):** 소수점 모의 체결(금액 기준·6자리, 최소 $1, $10 이하 수수료 무료), **여러 종목 봇**(최대 10개, 비율·현금 공유, 백테스트·DRY RUN·홈·시험해 보기·새 봇). 실제 가격(2016-10~, 월 $1,350, VOO 50·QQQ 50): 나처럼 모으기 +145.5% vs 매달 그냥 사기 +147.9%. **규칙 고르기**(고점에 쉬기 +10/+15/+20%·안 쉼, 하락장 기준 -10/-15/-20%; 12가지 조합 모두 +145~149%). 하락장에 "절반만 쓰기"는 하락장 단위 상태가 필요해 뺐다 (project.md 7절). **만든 뒤 종목·비율 바꾸기** (2026-10-03, 뺀 보유 종목은 비율 0으로 들고만 있기, 바꾼 기록 남김). **상장 1년 미만 종목**은 한 달 이력부터 있는 만큼으로 판단 (2026-10-03, 기존 결과 그대로). | **종목은 최대 10개** (2026-10-02 결정): 평소 가장 많이 사는 종목부터 고르게 하고 10개보다 적게(보통 2~5개) 고르도록 안내한다. 수십 개 종목을 사고파는 사용자는 대상이 아니다. 종목 가격 이력은 규칙 지표(1년 최고가·200일 평균)만큼 필요하며, 상장 1년 미만 종목은 있는 만큼의 기간으로 계산한다. **모의 체결을 금액 기준·소수점 6자리로** 바꿔 주가보다 적은 월 금액도 그대로 산다 (토스 금액 주문과 같은 방식, tossApi.md 9절). 규칙 틀: 입금(주기·금액·날짜), 종목 비율(VOO 50 · QQQ 50), 고점 기준(200일선 +%·안 쉼), 하락 기준(-10/-15/-20%), 매도(안 함). **봇 하나가 여러 종목을 다룬다** (한 계좌·공유 현금, 종목별 비율, 하락장 때 모아 둔 돈을 떨어진 종목에 쓰기). 실제로 월급 하나를 여러 종목에 나누는 습관과 같다. 기존 한 종목 전략은 종목이 하나인 경우로 그대로 동작 |
| N3 | 질문으로 나 만들기 | 완료 | 5~7개 쉬운 질문 → 규칙 틀 값 → 쉬운 말 요약 → "나처럼 10년 했다면" 즉시 백테스트(매달 그냥 사기와 비교) → 시작. AI 없이 선택지로. **완료 (2026-10-03):** 질문 5개(종목·비율, 금액, 날짜, 고점, 하락), 결과는 점수·판정 없이 두 금액과 그래프만. 버튼 하나로 봇 생성·시작. 시험해 보기 자산 그래프가 10년 일봉을 다 못 그리던 문제(막대 간격 하한)도 고침. **보완 (2026-10-03):** 첫 화면 안내("투자 습관을 복사할게요")와 복사할 수 없는 투자 안내, "주로 어떻게 사나요?"(매달 / 떨어졌을 때만, `regular`), 금액은 한 달 평균으로, 넣는 날은 "정해진 날 없어요" 가능. 떨어졌을 때만 사는 사람은 질문 4개 |
| N4 | 평행세계의 나 | 완료 | 내 규칙을 조금씩 바꾼 "다른 나"들을 같은 기간에 함께 계산해 나란히 보여준다 (예: 고점에도 안 쉬는 나, -20%까지 참는 나, 더 일찍 사는 나). 저장된 봇이 아니라 같은 일봉으로 그때그때 계산한다. 넣은 시점 반영 연 수익률(XIRR)과 지금 가치만 보여주고 점수·등수는 붙이지 않는다. 마음에 드는 나를 고르면 그 규칙으로 바꾼다. 시험해 보기(과거 10년)와 운영 중인 봇(시작 이후) 둘 다 **완료 (2026-10-03):** `POST /api/parallel`·`GET /api/bots/{id}/parallel`, 나·매달 그냥 사는 나·고점에도 안 쉬는 나·떨어졌을 때만 사는 나·-20%까지 참는 나·-5%에 바로 사는 나 (한 가지씩만 바꿈, 순서 고정, 넣는 돈은 모두 같게. "두 배로 넣은 나"는 결과가 뻔해 뺐다). 나 만들기 결과·시험해 보기·홈 봇 화면에. 실제 가격(2016-10~, QQQ 50·VOO 50, 월 $1,350, +15% 쉬기·-10%) 10년 두 종목 7개 세계 약 2.5초 |
| N5 | 홈 첫 화면으로 | 완료 | 평행세계 화면이 재미있게 나오면 홈 첫 화면을 "나 카피 봇 vs 매달 그냥 사기 + 평행세계의 나"로. 월간 정리는 앱 안에서 ("이번 달 나 카피 봇은 쉬었어요, 고점에도 안 쉬는 나는 샀어요") **완료 (2026-10-03):** 나 카피 봇이 있으면 홈 = 나 vs 매달 그냥 사기 + 월간 정리 한 줄 + 평행세계의 나 + 오늘의 판단, 예전 봇 화면은 "자세히 보기"(`#bot`). 평행세계 결과에 지난달·이번 달 산 금액(`recent`) 추가. "두 배로 넣은 나"는 결과가 뻔해 뺐다 |
| N6 | AI 인터뷰어 | 선택 (보류) | Claude API로 자유 대화 → 규칙 틀 JSON(구조화 출력, 스키마 검증) → N3 요약·백테스트 화면으로. 키는 `.secrets/`, 호출은 API 서버에서만, 대화 원문은 저장하지 않음. **보류 (2026-10-03, 사용자 결정):** 사람은 자기가 정확히 어떻게 투자하는지 잘 모르므로 선택지를 주고 고르게 하는 편이 더 정확하고, 길게 답했는데 제대로 반영되지 않으면 만족도가 오히려 낮다. 그래서 질문은 선택지로 둔다. 나중에 AI가 더 맞는 곳이 생기거나, 긴 답을 다 알아듣고 선택 패턴(규칙 틀)을 늘려 더 정확히 나처럼 만들 때 쓴다. 그때의 설계 메모: 퀴즈와 나란히 두는 다른 입력 방법, `update_rules` 도구 하나로 값만 채움, 스트리밍(SSE)·프롬프트 캐싱으로 지연 줄이기, 실패하면 알아낸 값을 들고 고르기로 넘어가기 |
| N7 | 도메인과 바깥 접속 | 완료 | **마일스톤 2 마지막에 꼭 한다** (2026-10-02, 사용자 결정). 도메인 구매(**사용자**) → `cloudflared` 컨테이너로 Tunnel → Access로 본인 이메일만 허용 (project.md 6절). Tailscale 앱 없이 폰에서 도메인으로 접속되고, Access 로그인 없이는 화면·API 모두 막히며, 공개 인바운드 포트 0개 유지 **준비 완료 (2026-10-03):** 운영 Compose에 `cloudflared`(tunnel 프로필, `.secrets/cloudflared.env`가 있을 때만 deploy.sh가 켬), API가 Cloudflare를 거쳐 온 요청의 Access 토큰을 한 번 더 확인(`CF_ACCESS_TEAM`·`CF_ACCESS_AUD`), PWA 매니페스트를 Access 쿠키와 함께 요청. **완료 (2026-10-03):** `https://app.trading-lab.me` 연결. 로그인 없이 화면·API 모두 막힘, api 이중 확인 403, 폰·노트북 로그인 확인, 공개 포트 0개 유지 (project.md 6절) |
| N8 | UI·UX 다듬기 | 진행 | **나 카피 봇이 이 프로젝트의 주 기능으로 보이게 하는 것까지가 마일스톤 2의 완성이다** (2026-10-03, 사용자 결정: 지금은 만든 것은 많아도 사용자 눈에는 기능 하나가 더해진 정도로 보인다). 사용자 흐름을 처음부터 따라가며 어색한 점을 고친다. 시험해 보기는 나처럼 모으기를 주력으로, 유명 전략들은 참고용 보조 자리로. 전략 이모지는 아마추어 느낌이 나서 뺀다 **1차 (2026-10-03):** 이름 통일(나 카피 봇·나처럼 투자·나 카피하기, 봇 이름 도플갱어 봇·QQQ 봇), 이모지 빼기, 홈 첫 화면을 늘 나 카피 봇 자리로(없으면 소개), 봇 목록 나누기, 시험해 보기 주력·참고 배치, 나 카피 봇 설정에 내 규칙·질문 다시 하기, 자세히 보기 판정 문장 빼기, 한국어 낱말 단위 줄바꿈 |
